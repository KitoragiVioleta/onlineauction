# Перевірка прототипу

## Передумови

- JDK 17 або новіший, що підтримує `javac --release 17`.
- PowerShell або інший командний рядок.
- Репозиторій відкрито в корені `onlineauction`.

## Компіляція та запуск

```powershell
Remove-Item -Recurse -Force build -ErrorAction SilentlyContinue
New-Item -ItemType Directory build | Out-Null
javac --release 17 -d build (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp build onlineauction.Main
```

Очікується завершення з кодом `0` не більш ніж за 10 секунд без запиту
введення. Команди й опис меж симуляції також мають бути наведені в кореневому
`README.md`.

## Перевірки сценаріїв

1. У stdout знайти створення лоту, `На модерації`, схвалення та
   `Активні торги`.
2. Перевірити повідомлення про прийняту допустиму ставку та відхилення
   ставки поза часом або нижче мінімального кроку.
3. Перевірити `Завершено з переможцем`, ім'я переможця, підсумкову ціну й
   повідомлення симульованої оплати.
4. Перевірити альтернативний потік: `Відхилено`, пояснення, повторне
   подання та повернення до `На модерації`.
5. Перевірити `Знято`, відмову у знятті активного лоту та
   `Завершено без переможця`.
6. Повторити запуск і переконатися, що порядок і зміст ключових результатів
   стабільні.

## Перевірка документації

- Звірити класи, поля, методи й зв'язки реалізації з
  `docs/class.mmd` та `docs/crc.xlsx`.
- Звірити виклики й повідомлення з `docs/sequence.mmd`.
- Звірити всі сім станів і переходи з `docs/state.mmd`.
- Звірити ролі та варіанти використання з `docs/usecase.puml`.
- Перевірити, що README містить ті самі команди компіляції та запуску.
